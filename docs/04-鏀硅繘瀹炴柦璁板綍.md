# 改进实施记录

> 全部改动都基于 12 题批测的实测证据。每条都写明"观察到什么 → 改了什么 → 怎么验证"。

## A. 已实施并验证

### A1. flag 选取：从排序改为证据判定

**观察**：CTFARENA-015 的日志里同时出现 3 个 flag，`sorted()[-1]` 取到了跨题残留的诱饵，平台判 `correct: false`——但 agent 其实做对了。

**改动**：新增 `src/ctf_strix/flag_extract.py`

| 判据 | 处理 |
|---|---|
| flag 距本题靶机 host 最近 | 取胜出者（相对名次，不用绝对阈值） |
| 紧邻 `ctf_recon.md` 且该文件自称的靶机不是本题 | 直接排除 |
| 距本题 host 超过 800 字符仍无更近者 | 排除（防"唯一候选必然最近"的退化解） |
| `FLAG{...}` 纯点占位符 | 排除 |

**验证**：6 个回归场景 + 11 份真实日志离线复判。8 道原本 `correct: true` 的题零回归；015 改判为选中真答案 `FLAG{5245c057...}`。

### A2. 工具日志截断

**观察**：`output[:300]` 把 CTFARENA-013 的 flag 劈成 `FLAG{b9\n`，完整 flag 从未进日志。

**改动**：`scripts/run_strix_ctf.py` —— 输出/参数含 `FLAG{` 时上限提到 4000 字符，其余仍裁剪。**验证**：`od -c` 复核 013 日志确认为物理截断，非 agent 失败。

### A3. 跨题污染隔离

**观察**：agent 主动 `grep -r FLAG{ /workspace /tmp`，把冒烟测试和上一题日志里的 flag 当成本题答案。

**改动**：每题独立沙箱 `cwd=/tmp/ctfbox/<题名>/`（strix 的 `runs` 目录跟着 `cwd` 走，产品也一并隔离）+ 目标定义里明确禁令。

**验证**：run5 日志确认 agent 落在 `/tmp/sandbox-local-eyd7znni`，未再跨题。

### A4. 预算分层

**观察**：hard 题失败三道里两道是预算耗尽。010 在 25 轮处被强停，停时**正在**伪造 JWT。

**改动**：easy 25/780s、medium 40/1248s、hard 60/1794s。**验证**：run5 确认 018 按 40/1248 执行。

### A5. 枚举守卫（程序强制）

**观察**：两版文字规则（"6 次后必须转向假设"）**都没生效**——018 在新规则下仍把同一族端点刷了 8 次。原因：上下文里的自我约束会随轮次衰减。

**改动**：新增 `src/ctf_strix/enum_guard.py`，在 `FunctionTool.on_invoke_tool` 层做包装（照抄 strix 自己的 `_with_bounded_result` 手法，不动 vendor）：

- 归一化指纹 = 工具名 + 目标 host + 路径族（取倒数第二段，让 `/api/coins/stats` 与 `/api/coins/tiers` 算同族）
- 第 4 次起在**工具结果尾部**注入警告；第 7 次起升级为"禁止再打这一族"
- 爆破工具（ffuf/dirsearch/gobuster/nuclei/FUZZ 占位符）无条件计入

**验证**：端到端跑通——第 4 次 `len=233 含警告=True`，第 5、6 次不再刷屏；真实日志重放识别出 `api` 族被刷 8 次并触发警告。

### A6. 墙钟超时形同虚设

**观察**：`subprocess.run(timeout=)` 只杀直接子进程，strix fork 出的孙进程变孤儿继续打靶机。018 预算 1248s，实跑到 47 次调用仍未停。

**改动**：`start_new_session=True` + `os.killpg`，超时按进程组 SIGTERM→SIGKILL。**验证**：构造带孙进程的任务，杀前 `sleep` 计数 1 → 杀后 0。

### A7. token 计量

**观察**：strix 的 `provider_data` 只留模型名和 response_id，**把 API 返回的 usage 丢掉了**。此前只能猜。

**改动**：新增 `scripts/measure_tokens.py`，从 `agents.db` 的完整消息历史重建用量（每次调用把已有历史全量重发，按轮累计）。

**校准**（实测而非拍脑袋）：

| 样本 | 字符 | token | 比值 |
|---|---|---|---|
| 英文输出 | 230 | 44 | 5.23 |
| 中文思维链 | 3910 | 800 | 4.89 |

取 **5.0**。最初用的 3.2 来自"字节数÷token"，遇中文会严重低估。
