## 4. 失败归因：9 道零解出题在看什么

| 现象 | 证据 | 结论 |
|---|---|---|
| 失败耗时远高于成功 | 成功 p50：medium 60s / hard 70s；失败 p50：medium 267s / hard **551s**（max 815s） | 不是"没时间"，是**方向错后越陷越深** |

| 枚举失效 | 043：`enum_keys=4, enum_hits=0`，3320 个候选塞进**一条** `exec_command` | 现有 `enum_guard` 对生成式枚举**完全看不见**（`sweep_guard` 已写未接线）|
| 证据链断裂 | 043 的 **52 个 `note_*` ID 全部只出现在 `@@INCLUDE:` 里，一次都没被直接 GET**（`/notes/<id>` 命中 0 次） | 答案无法溯源到本 run 的工具输出（P20-b 未实现）；交接里写的「11 个」是低估，实测 52 个 |
