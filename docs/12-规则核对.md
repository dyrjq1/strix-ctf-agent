## 2. 由字段直接推出的硬约束（不是我的判断，是字段语义）

| 约束 | 依据字段 |
|---|---|
| agent 进程不得访问外网（含下载字典、查资料、调第三方 API） | `agent_internet = deny` |
| 练习赛同一时刻最多 1 个实例；正式赛另见 QA#26（Agent 并发 ≤3） | `max_instances_per_team_effective = 1`（练习赛） |
| 允许用 agent 参赛 | `agents_allowed = True` |
| 会话结束即删除实例，宽限 15 分钟 | `session_end_mode = delete`, `session_end_grace_s = 900` |
| TCP 型题目走 TLS SNI 接入 | `tcp_access = tls_sni` |

> `hosted_eval = false` 这一条**在本接口对象里没有同名字段**。可核对的是
> `eval_standard = False`，它只说明**练习赛 CTFARENA 不走平台标准评测**，
> **不能外推到正式赛**。官方 QA#5/#16/#24 明确：正式赛智能体跑在指定 VPS
> （4C/8G/100G/x64），赛前上传一次，重启后自主执行；CTFY-0001 契约要求
> 读 `task.json`、写 `result.json`。因此正式赛**需要可独立运行的 agent 包**
> （镜像/入口），此前"不交镜像"的结论作废。

## 4. 尚未有权威依据的两点（先按保守执行）

1. **平台给出的 `description` / `tags` 能不能喂给 agent？**
   现状：这两个字段在题目页面对所有人公开，`hints_released = 0` 说明"提示"
   是另一套独立对象（有 `hint_cost_mode`），tags 不属于提示体系。
   处置：允许使用，但在结果行里记录 `brief_chars`，一旦主办方有异议可以整批剔除。
   **未与主办方书面确认，属于保守解释，不是定论。**
2. **自动提交是否允许？**
   平台提供 `POST /api/v1/submissions`，且 `format = questions` 按答案判分；
   HANDOFF 的红线只禁"人工代为提交"。处置：保留 agent 自己提交
   （`--autosubmit`），批测由 `batch_eval` 代交，均不使用人工。

## 5. 复核：正式赛是否有选择题（2026-10-31）

**复核方式**：线上重拉 `GET /api/v1/competitions?kind=event&limit=100`，
并解析事件对象里的 `handbook` 全文与平台 OpenAPI 的 `QuestionPublicInfo`。

**事实**：

- 6 个 `kind=event` 中，4 个正式赛事（TPCTF Agent / Human-AI、京华杯 PKU / 清华）
  均为 `format=questions`、`challenges_withheld=true`、`challenge_count=null`；
- `GET /api/v1/meta` 对应 OpenAPI 的 `CompetitionInfo.format` 枚举为
  `questions / engagement / practice / awd / authoring / custom`，
  **`questions` 是"按 question 提交答案"的赛制格式，不是题型**；
- 真正的选择题由 `QuestionPublicInfo.choices: string[] | null` 标识，
  `choices` 非空才是选择题，`null` 则是普通 flag/文本题；
- Agent Track 与 Human-AI Track 的 handbook（`handbook_updated_at=2026-10-28`）
  命题方向只有 Crypto / Reverse / Misc / Web / Pwn / AI 安全六类实操题，
  全文检索"选择 / 单选 / 多选 / 客观题 / quiz / choice"无题型相关表述；
  唯一一处"选择"是"参赛团队可根据自身技术特点自由选择（赛道）"。

**结论（已被官方 QA 表证实）**：

1. QA#26 明确：智能体赛道是 **CTF 解题赛制**，题型为
   Crypto / RE / Pwn / Web / Misc + AI Security **六类全含**；
2. QA#31 明确：11-22 正式赛解题题为 11-21 智能体在 **Web / Pwn / AI Security**
   三个方向出题并审核通过的题目；结合 QA#23（解题在 11-14/15 与 11-22），
   11-14/15 **不能假设只考 Web/Pwn/AI**，应按 QA#26 的六类准备；
3. 因此**正式赛没有选择题**，此前"开赛前无法 100% 排除"的保留意见撤销；
4. 选择题通道已下线：`scripts/qa_eval.py` 移入 `archive/`，设计知识保留在
   `docs/13-选择题通道设计.md`（标注"已停用"）。
