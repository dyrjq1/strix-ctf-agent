## 3. 我这边做什么（四步，全程不打印明文）

```powershell
# 步骤 1：把 spec 编码成 base64（凭据不落本地磁盘，只在内存里过一次）
$spec = "<四行原文>"
$b64  = [Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes($spec))

# 步骤 2：落盘（新增脚本 deploy/drop_lane_specs.sh，600，原子替换，失败不覆盖旧文件）
$b64 | ssh root@<HOST> 'bash /root/deploy/strix-ctf-agent/deploy/drop_lane_specs.sh /root/lane_specs.txt'
# 期望：DROP_OK lines=4 + 四行掩码（key=pk_xxx…xxx）
```

```bash
# 步骤 3：一条命令装车道（钉边缘 IP → 查模型名 → 原子写 600 → 顺带跑车道探测）
cd ~/deploy/strix-ctf-agent
bash deploy/setup_lanes.sh /root/lane_specs.txt --out /root/lanes.conf --verify
# 期望：每家 PICK_OK + model=xxx → SETUP_LANES_OK lanes=4 → lane probe 每条 HTTP 200
```

```bash
# 步骤 4：核对（只读，掩码）
stat -c '%a %n' /root/lanes.conf
awk -F'|' '{printf "  %-10s %s  model=%s  %s…%s\n",$1,$2,$4,substr($3,1,6),substr($3,length($3)-2)}' /root/lanes.conf
```

## 4. 判据表（四条同时成立才算彩排通过）

| # | 判据 | 期望 |
|---|---|---|
| B1 | 落盘 | `DROP_OK lines=4`；`stat` 显示 `600` |
| B2 | 装车 | `SETUP_LANES_OK lanes=4` |
| B3 | 每家真能回话 | `lane probe` 四行全 `PASS ... HTTP 200` |
| B4 | 模型名定下来了 | 四行都有 `model=`，且不是我猜的（来自 `/models` 回显） |

任何一条不成立 → 按 §6 处置，不要往下走。

## 5. 负向演练（必做，约 2 分钟）

彩排的价值一半在「坏了怎么办」。故意做坏一条：

```bash
# 在 VPS 上复制一份 spec，把最后一行的 key 砍掉 3 个字符
cp /root/lane_specs.txt /root/lane_specs.bad
sed -i '$ s/.$//; $ s/.$//; $ s/.$//' /root/lane_specs.bad
bash deploy/setup_lanes.sh /root/lane_specs.bad --out /root/lanes.conf
```

要求看到并确认三件事：

1. 报错指到具体那一行（`FAIL: ... /models 三次都没返回模型清单`），不是笼统失败；
2. 结尾是 `SETUP_LANES_FAIL ...（/root/lanes.conf 未改动）`；
3. `lanes.conf` 真的没变（`awk` 再看一次，还是四条好的）。

然后删掉 `/root/lane_specs.bad`，用好的 spec 复跑一次确认恢复绿。

**第二个负向（可选）**：把某行第 4 段模型名写成 `gpt-4o`，期望 `WARN: 指定模型不在清单里，仍按你写的用` ——
这条说明「模型名写错不会被拦」，所以正式开赛只认 `lane probe` 的 200。

## 6. 失败处置

| 现象 | 处置 |
|---|---|
| `DROP_FAIL bad=1` | 某行缺段（少了 `|` 或 key 没抄全），把原文重发一次 |
| `DROP_FAIL 空内容` | 传输编码问题；改用 §2 的另一种格式重发 |
| 某家 `/models` 三次全空 | 凭据过期/抄错 → 重建该家会话；或先跳过它，其余照跑 |
| `FAIL: 钉 IP 没选出可用节点` | 边缘节点全坏或本机出网断 → 重跑一次；仍失败就查本机网络 |
| `lane probe` 某家 401/403 | key 不对或会话已废 → 重建 |
| `lane probe` 某家超时 60–75s | 钉到了坏边缘 → `bash deploy/pick_gateway_ip.sh <host>` 重选 |
